# HECATE v1.0 Release Notes
**Release Date:** December 2025

HECATE v1.0 establishes the foundation for our AI-native reliability control system, implementing basic observability, anomaly detection, and automated remediation.

## Key Features
- **Telemetry Scraper & Event Bus:** Scrapes CPU, memory, and restart metrics, and publishes telemetry events.
- **Isolation Forest Anomaly Detection:** Machine learning model to detect infrastructure anomalies.
- **Rule-Based Root Cause Analysis (RCA):** Localizes faults based on historical incident signatures.
- **Automated Remediation Agent:** Directly executes action commands (e.g. `restart_pod`, `scale_deployment`) on target Kubernetes namespaces.
