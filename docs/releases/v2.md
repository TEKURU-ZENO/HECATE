# HECATE v2.0 Production Edition Release Notes
**Release Date:** June 2026

HECATE v2.0 introduces the **Autonomous Infrastructure Simulation & Planning** generation. Rather than executing remediation scripts blindly, HECATE first simulates and validates actions inside a virtual infrastructure twin.

## Architectural Changes
The control loop is upgraded from a direct action-response model to a cognitive planning loop:
**Observe → Detect → Diagnose → Recommend → SIMULATE → Score Outcomes → Execute**

## Key Features
- **Digital Twin Service:** Maintains topology, workload state, and runs simulations using safety metrics (Success Probability, projected MTTR, cost, and blast radius).
- **Simulation Agent:** Reasoner that tests multiple playbook sequences and ranks them by Twin Score.
- **Progressive Delivery Safety Scoring:** Simulates Rolling, Blue-Green, and Canary rollout strategies.
- **Multi-Tenancy context partitioning:** Partitions databases and logs using `X-Tenant-ID` headers.
- **Cryptographic Signature Verification:** Enforces HMAC-SHA256 signatures on decisions before the Remediation Agent executes them.
- **Standardized Health Probes:** Uniform `/health`, `/ready`, `/live`, and `/metrics` APIs across all services.
- **OpenTelemetry context propagation:** Propagates tracing context over synchronous API calls and asynchronous event streams.

## HECATE v2.0.5 — Research Evaluation Harness (June 28, 2026)
This release introduces the modular, scientific evaluation engine under the `evaluation/` directory, designed for production reliability verification:
- **Scenario & Metrics Registry:** Exposes standardized units, directions, and scenario failure injectors (OOM crash, memory leak, packet loss, DNS failures, etc.).
- **Baselines & Ablation Studies:** Runs evaluations against 7 baseline control groups and simulates components removal to assess individual subsystem values.
- **Statistical Significance Tests:** Leverages Welch's t-test ($p < 0.05$), Cohen's d effect size, Mann-Whitney U rank-sum, and bootstrap confidence intervals.
- **Visual Analytics Reports:** Generates vector SVG curves, LaTeX tables, and an interactive dark-theme `evaluation.html` dashboard.
- **Git-style CLI Delta Comparator:** Added `python scripts/evaluate.py --compare` to display change deltas in the terminal.
