# Security Policy

## Supported Versions
We support security updates for the following versions of HECATE:

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability
If you discover a security vulnerability within HECATE, please report it immediately by email to security@hecate.io.

Please do not open a public issue on GitHub for security vulnerabilities.

Once we receive your report, we will:
1. Acknowledge receipt of the report within 24 hours.
2. Investigate the issue and provide a fix/remediation plan.
3. Coordinate a public disclosure once a patch is ready.
